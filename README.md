# Job Application Tracker

A full-stack app to help new grads and job seekers organize 
and track their job applications in one place.

> 🚧 Currently in development — actively building!

---

## Roadmap
- [x] CLI version
- [x] SQLite database integration
- [ ] FastAPI backend
- [ ] PostgreSQL migration
- [ ] Frontend (in planning)

---

## Tech stack
`Python` `FastAPI` `SQLite` `PostgreSQL`

---

## Why I built this!
I'm a new grad actively job hunting and wanted a better way 
to track applications than a spreadsheet. So I built my own.

---

## Getting started

```bash
git clone https://github.com/yourusername/job-tracker.git
cd job-tracker
pip install -r requirements.txt
python main.py
```
